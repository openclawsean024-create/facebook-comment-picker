# FB 留言抽獎助手 — Chrome 擴充套件 v1.1

## 安裝（30 秒搞定）

1. 下載 `fb-comment-picker-extension.zip` 並解壓縮
2. Chrome 網址列輸入 `chrome://extensions/`
3. 右上角打開「**開發人員模式**」
4. 點「**載入未封裝項目**」→ 選擇解壓縮後的資料夾

## 使用方式

### 🎯 兩種抓取模式

**📥 完整抓取（推薦）**
- 自動捲動到 FB 貼文底部
- 重複點「查看更多留言」按鈕
- 抓所有留言後複製到剪貼簿
- 預計 10-30 秒（取決於留言數）

**⚡ 快速抓取**
- 只抓目前可見的留言
- 適合「先抓一次試試」或「留言很少」的貼文

### 📋 完整流程

1. 打開 FB 貼文頁（含 Reels、Live、一般貼文）
2. **登入你的 FB 帳號**（擴充套件用你的 session 抓）
3. 點 Chrome 工具列的擴充套件圖示
4. 選「完整抓取」或「快速抓取」
5. 等 popup 顯示「已抓到 N 筆留言」
6. 回到 [FB 留言抽獎工具](https://src-tau-ruddy-65.vercel.app/)
7. **工具會自動偵測剪貼簿變化 → 自動匯入 → 自動解析**

## 隱私

- ❌ 不收集任何資料
- ❌ 不發送任何請求到外部伺服器
- ❌ 不申請 cookies 或個人資料權限
- ✅ 完全在你的瀏覽器內執行
- ✅ 開源透明：所有程式碼可檢視

## 限制

- 需要 FB 已登入 session
- 完整抓取需 10-30 秒（取決於留言數）
- 公開貼文都能抓，私密貼文只有你自己能抓
